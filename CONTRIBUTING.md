# Contributing

Propose changes through issues or pull requests. Describe the user situation and why the current material is insufficient. Cite primary sources for factual assertions and identify dates/market scope where relevant.

Keep English as the primary language. Language-specific additions should explain terminology and source differences. Do not submit private personal records, confidential client data, speculative allegations or fabricated observations.

Run `python3 tools/validate.py` before submission. Documentation/templates/artwork use CC BY 4.0; validator changes use MIT. Do not imply provider endorsement or guaranteed outcomes.
