# Assign ownership and a review cadence

Start with the decisions the public record supports: a partnership, an appointment, a board evaluation or another defined context. Use that context to prioritize factual accuracy and evidence, rather than follower counts or content volume.

## Owners

Name the subject/authorized approver, biography editor, evidence reviewer and technical owner. One person may fill several roles, but the responsibilities should remain clear. Define which changes need legal, compliance, privacy or employer review in the actual situation; this template does not establish a universal approval policy.

## Events that open a review

Role or organization changes, new publications, material credential changes, disputed records, acquired/divested companies, significant naming changes and newly observed identity confusion. Set a periodic review interval suited to the record; no particular interval guarantees current search or AI answers.

## Review record

For each action, retain the finding, source artifact, approved change, owner, effective date, implementation date and verification result. Keep client or employment materials in appropriate private storage, not this public repository.

## Diagnostics

Useful operational counts include unresolved factual discrepancies, claims awaiting evidence, correction requests by status and time to review a new issue. Define the denominator and scope. If tracking AI answers, retain engine, interface, prompt, market, language and date; do not roll these into an unvalidated universal reputation score.
